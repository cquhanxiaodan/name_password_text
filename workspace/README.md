## 浏览器插件使用指南

### 功能界面

插件主界面包含以下区域：

| 区域 | 说明 |
|------|------|
| 顶部 Header | 插件名称和说明 |
| 同步设置区 | 配置服务器地址和令牌 |
| 统计区 | 显示浏览器密码数量和已同步数量 |
| 搜索区 | 搜索过滤密码列表 |
| 密码列表区 | 显示所有已导入的密码 |
| 操作区 | 导入/导出按钮 |
| 底部 Footer | 安全声明 |

### 功能一：导入浏览器密码

由于浏览器安全限制，插件无法直接读取浏览器保存的密码，需要手动导出 CSV 再导入：

**从 Chrome 导出密码：**

1. 打开 Chrome 设置：`chrome://settings/`
2. 点击「自动填充」→「密码管理器」
3. 点击右上角「导出密码」
4. 确认导出，下载 `chrome_passwords.csv` 文件

**导入到插件：**

1. 点击浏览器工具栏中的插件图标
2. 在「同步设置区」找到文件导入区域
3. 点击「选择文件」，选中下载的 CSV 文件
4. 点击「导入CSV」按钮
5. 密码列表会自动更新

### 功能二：同步到云端服务器

#### 方式一：同步到自建服务器

1. **启动服务器**（在电脑终端执行）：
   ```bash
   cd workspace
   npm run server
   ```
   服务器运行在 `http://localhost:3001`

2. **在插件中配置服务器**：
   - 服务器地址填写：`http://localhost:3001`
   - 点击「注册」按钮获取访问令牌
   - 令牌会自动保存

3. **同步密码到服务器**：
   - 点击「🔄 同步到服务器」按钮
   - 插件中的密码会上传到服务器

4. **从服务器拉取密码**：
   - 点击「📥 从服务器拉取」按钮
   - 服务器上的密码会下载到插件

#### 方式二：配合 Web 应用使用

1. **启动 Web 应用**：
   ```bash
   cd workspace
   npm run dev
   ```
   Web 应用运行在 `http://localhost:5173`

2. **导出密码到 Web 应用**：
   - 在 Web 应用中打开侧边栏「导出数据」
   - 选择「浏览器兼容格式 (CSV)」导出
   - 在插件中通过 CSV 导入方式间接同步

### 功能三：自动填充（需配合自建服务器）

当配置了自建服务器后，可以使用自动填充功能：

1. 打开需要登录的网页
2. 点击插件图标
3. 在密码列表中点击要使用的账号
4. 插件会自动在页面中填入用户名和密码

### 功能四：搜索过滤

在搜索框中输入关键词，可以快速过滤密码列表：

- 支持按网站名称搜索
- 支持按用户名搜索
- 支持按网址搜索

### 常见问题

**Q: 插件无法读取浏览器的密码？**
A: 由于浏览器安全限制，插件无法直接读取。需要手动从浏览器导出 CSV，步骤见「导入浏览器密码」。

**Q: 同步按钮点击无反应？**
A: 请先确保服务器已启动（`npm run server`），且服务器地址和令牌配置正确。

**Q: 导入 CSV 后密码显示乱码？**
A: 请确保 CSV 文件保存时使用 UTF-8 编码。

## 功能介绍

### 创建保险库

首次使用需要设置主密码，这个密码用于加密你的数据。

**重要**：请记住主密码，丢失将无法恢复数据！

### 添加凭据

1. 点击右上角「+ 添加凭据」
2. 填写网站/应用名称、用户名、密码
3. 可选择生成随机密码

### 密码生成器

点击 ⚡ 按钮可打开密码生成器：

- **密码长度**：8-64 位可调
- **字符类型**：小写字母、大写字母、数字、特殊符号
- **密码短语**：使用多个单词组合

### 导入导出

#### 导出格式

| 格式 | 用途 |
|------|------|
| 🌐 浏览器兼容 CSV | 可直接导入 Chrome/Edge 等浏览器 |
| 📄 完整 CSV | 包含所有字段，适合其他密码管理器 |
| 📋 JSON | 通用格式，适合程序处理 |

#### 导入来源

支持导入以下来源导出的 CSV：
- Chrome / Edge 浏览器
- Firefox 浏览器
- 1Password
- LastPass
- Bitwarden
- 其他支持 CSV 导出的密码管理器

### 主题切换

点击右上角 🎨 按钮可切换 6 种主题颜色：
- 黄褐（默认）
- 蓝色
- 绿色
- 橙色
- 粉色
- 青色

## 数据同步方案

由于数据存储在浏览器本地，不同设备间同步需要借助中间方案：

### 方案一：导入/导出 CSV

1. 设备 A：导出数据为 CSV
2. 设备 B：导入 CSV 文件

### 方案二：使用网盘同步

1. 导出 CSV 到 OneDrive / iCloud / Google Drive 等网盘
2. 在另一设备登录网盘下载 CSV
3. 导入到密码管理器

### 方案三：浏览器插件同步

1. Chrome 安装插件，导入浏览器密码
2. 插件支持导出 CSV
3. 导入到 Web 应用

### 方案四：自建云端同步服务器

可以部署自己的同步服务器，实现多设备密码同步。

#### 启动服务器

```bash
cd workspace
npm run server
```

服务器默认运行在 `http://localhost:3001`

#### API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/register` | POST | 注册新账号，获取访问令牌 |
| `/api/login` | POST | 验证令牌 |
| `/api/passwords` | GET | 获取密码列表 |
| `/api/import` | POST | 导入密码 (CSV) |
| `/api/passwords` | DELETE | 清空密码 |

#### 使用同步功能

1. 在 Web 应用中点击侧边栏「☁️ 云端同步」
2. 输入服务器地址和访问令牌
3. 连接成功后可进行：
   - **Push**：将本地密码同步到云端
   - **Pull**：从云端拉取密码到本地

#### 数据存储

服务器数据存储在 `data/passwords.json` 文件中。

## 技术栈

- **前端框架**：原生 JavaScript（无框架依赖）
- **构建工具**：Vite
