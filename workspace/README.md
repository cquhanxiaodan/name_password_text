# Password Manager

一个简洁美观的密码管理器，支持本地加密存储、密码生成、导入导出等功能。

## 部署方式

### 方式一：直接运行（推荐）

```bash
cd workspace
npm install
npm run dev
```

访问 `http://localhost:5173` 即可使用。

### 方式二：构建静态文件

```bash
cd workspace
npm install
npm run build
```

构建产物在 `dist/` 目录，可部署到任意静态服务器。

## 功能特性

- **安全加密**：AES-GCM 本地加密，密码本地存储
- **密码生成**：支持自定义长度、字符类型、密码短语模式
- **密码健康分析**：评估密码强度
- **多主题**：支持 6 种主题颜色切换
- **导入导出**：支持 CSV 和 JSON 格式
- **分组管理**：按网站/应用分组管理凭据
- **搜索过滤**：快速搜索凭据

## 主题切换

点击右上角 🎨 按钮可切换主题：

- 黄褐（默认）
- 蓝色
- 绿色
- 橙色
- 粉色
- 青色

## 数据存储

所有数据存储在浏览器本地（IndexedDB），不会上传到任何服务器。

如需备份，可通过「设置」中的导入/导出功能进行数据备份。
