# 浏览器扩展 - 密码管理器助手

一个 Chrome/Edge 浏览器扩展，可以与密码管理器 Web 应用联动，支持导入浏览器已保存的密码并自动填充表单。

## 功能特性

- **导入浏览器密码**：从 Chrome/Edge 读取已保存的密码
- **自动填充**：在网页上自动填充用户名和密码
- **同步到 Web**：将浏览器密码同步到密码管理器 Web 应用
- **搜索过滤**：快速搜索已保存的密码
- **CSV 导出**：导出为 CSV 格式，方便导入其他系统

## 安装方式

### Chrome / Edge (Chromium)

1. 打开扩展管理页面：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`

2. 开启右上角的「开发者模式」

3. 点击「加载已解压的扩展程序」

4. 选择 `browser-extension` 文件夹

## 使用方法

### 1. 导入浏览器密码

1. 点击浏览器工具栏中的扩展图标
2. 点击「📥 导入浏览器密码」按钮
3. 浏览器会显示已保存的密码列表

### 2. 自动填充表单

1. 打开需要登录的网页
2. 点击扩展图标
3. 点击要使用的账号
4. 扩展会自动填充用户名和密码

### 3. 同步到密码管理器 Web

1. 在扩展中输入密码管理器 Web 应用的地址（如 `http://localhost:5173`）
2. 点击「同步」按钮
3. 密码会通过 CSV 格式导入到 Web 应用

## 文件结构

```
browser-extension/
├── manifest.json      # 扩展配置文件
├── popup.html         # 弹出窗口界面
├── popup.js           # 弹出窗口逻辑
├── background.js      # 后台服务脚本
├── content.js         # 内容脚本（注入网页）
└── icons/             # 图标文件
```

## 注意事项

- 扩展仅在本地使用，不会上传任何数据到第三方服务器
- 同步功能需要密码管理器 Web 应用支持 CSV 导入
- 自动填充功能会自动识别页面上的用户名和密码字段

## 技术说明

- 使用 Manifest V3 API
- 支持 Chrome 88+ 和 Edge 88+
- 密码数据存储在浏览器本地（chrome.storage.local）
